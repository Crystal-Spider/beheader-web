# Milestone 8: complete generator experience

Implemented on 2026-10-16. The selected dark utility/lab shell now connects to actual inspection, compatibility planning, generation, cancellation and file-backed downloads. AGENTS.md remains local.

The global picker and page-wide drop accept real local files. Six role-specific badges use the existing availability model, gray disabled slots and accessible reasons; the picker accept hint excludes unavailable formats. Picker/drop contents still receive authoritative core validation. The interface supports file metadata, explicit role reassignment, removal/replacement, selected ordering, multiple archives, collision paths, an HTML entry path, asset ZIPs, appendables and bounded header payloads. Unresolved HTML references block generation until fixed or explicitly retained; changing selected inputs resets that consent. No selected content is previewed or executed in the application.

A runtime service owns File objects and output lifetimes. NgRx Store/Effects own only metadata, progress, plans, safe diagnostics and artifact references. Effects serialize operations; selection controls are disabled while work runs. Cancellation works during processing and between cleanup/inspection and the next worker. Stage-scoped measured progress uses percentages with byte, file-count or media-time units. Failed jobs can be corrected and retried.

Downloads resolve OPFS artifacts as file-backed Files and use browser object URLs, without a complete output ArrayBuffer. Users choose an output base name and a validated extension; all extensions download identical bytes. The interface explains each supported interpretation and consumer limitations. Actual output-name/extension preferences are remembered; files, selection, reference consent, paths and output references are not restored after reload. Language remains independently remembered. Redistributable original image/HTML/audio examples are local assets.

Both English and Italian include all stable diagnostics and generator controls. Missing resources, unsupported structures and resource failures receive actionable text. Unexpected errors offer a short user-initiated GitHub issue link and downloadable diagnostics. Reports allowlist diagnostic codes/severity and browser metadata, excluding input IDs, filenames, paths, reference URLs, diagnostic details and contents. No issue is submitted automatically.

Validation: frozen installation; lint with zero warnings; strict application/tooling/worker types; 110 unit tests; 76 Chromium flows; existing audio matrix with 32 functional Chromium/Firefox flows and three platform probes (16 reviewed Windows WebKit skips); production build; independent advanced/combination/audio/image/media validators. New flows cover identical-byte downloads with different extensions, ephemeral selection, preference persistence, bypassed filters, removal/replacement/drop assignment, explicit unresolved consent, uploaded-HTML nonexecution, worker-error diagnostics, cancellation/retry, archive ordering, asset-role correction, header limits, and the complete Italian workflow at 320 pixels. Desktop and Italian mobile result screenshots are saved to ignored test-results/ for visual inspection.

Reproduce with pnpm check, python scripts/verify-advanced-fixtures.py, python scripts/verify-audio-fixtures.py, and python scripts/verify-polyglot-fixtures.py. The complete generator stylesheet is about 5.1 kB, above the original 4 kB warning budget but below the 8 kB error budget; Angular also reports CSS Tree's existing optional source-map CommonJS warning. Actual Safari/iOS, Android and full release acceptance remain Milestone 10.

Milestone 9 follows separately: offline reopening, idle-only updates, storage estimates/bounds, abandoned-job cleanup and large-file resilience. No publication or deployment is included.
