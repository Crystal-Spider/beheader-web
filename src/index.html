Beheader Web

A free, local polyglot file generator.

Combine supported images, audio or video, HTML, PDFs and archives into a single file that works as more than one format. Choose files from at least two different types, combine them, then choose an extension and open the result in a compatible app.

Your files stay on your device. Processing runs locally, with offline reopening available after the application has been cached.

Inspired by Beheader. An independent, unaffiliated project.
