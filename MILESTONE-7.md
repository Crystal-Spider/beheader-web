# Milestone 7: standalone HTML and advanced payloads

Completed on 2026-10-16. This milestone adds parser-based static HTML resource bundling and ordered raw payloads; full selection controls remain Milestone 8. AGENTS.md remains local.

HTML is parsed with pinned parse5 8.0.1; CSS is parsed with CSS Tree 3.2.1. A selected asset ZIP is inspected through the same seekable, strict archive path as ordinary archives. References resolve relative to the HTML entry path (editable as metadata), the first HTML base URL, and each referenced stylesheet. Supplied images, fonts, CSS imports/URLs, image srcset candidates, and ordinary external scripts become local data URLs. CSS imports retain their media/layer/supports syntax. Script bytes are base64 encoded, so literal script terminators cannot break out of generated markup. Inline CSS escapes literal less-than characters. Processing never executes supplied content or fetches remote resources.

Missing resources, remote URLs, reference cycles, modules, iframe sources, unsupported CSS syntax and restrictive HTML CSP metadata are reported in display-only reference details. Planning blocks until references are fixed or the caller explicitly supplies allowUnresolved. Continuation retains the unresolved references. Module dependency rewriting and dynamic script requests remain outside the agreed scope; ordinary JavaScript is not analyzed for runtime fetches. Existing CSP can prevent data resources from loading after explicit continuation. References in opaque resources such as SVG images are not recursively rewritten; supply self-contained image assets.

To bound syntax-tree and base64 allocation, HTML and each referenced asset are limited to 8 MiB, cumulative referenced expansion to 32 MiB, and emitted bundle data/final HTML to 64 MiB. Traversal allows 100,000 HTML nodes, 4,096 reference operations, and a 32-level import chain. These are implementation resource limits in addition to the existing ZIP expansion and input bounds. Oversized inputs fail before parser allocation. Repeated references count against work/expansion bounds. CRC and actual extracted sizes are checked for every consumed asset; unused assets are not extracted.

Appendables are copied in selected order inside the media skip region before PDF/ZIP extensions. They do not create independent interpretations. Extra-header data fills only the space left by the actual image/HTML/PDF framing in the fixed header; the plan reports the available byte count. Oversized data is rejected, and HTML compositions reject header bytes containing a comment terminator. Neither auxiliary role counts toward the two-family minimum. Existing format/output bounds and cancellation apply.

Validation: frozen installation, lint, strict application/tooling/worker types, 106 unit tests, 68 Chromium flows, and the existing audio matrix (32 functional Chromium/Firefox flows plus three capability probes; 16 reviewed Windows WebKit skips). The new browser flow opens a controlled all-family artifact offline and verifies nested CSS, image srcset, a script containing a terminator, and UTF-8 text. Ordered appendable and header bytes are checked. Independent Pillow, FFmpeg, Poppler, and ZIP checks validate all interpretations of that artifact, alongside all earlier combination/audio fixtures. Actual Safari/device verification remains Milestone 10.

Reproduce with pnpm check, then python scripts/verify-advanced-fixtures.py, python scripts/verify-audio-fixtures.py, and python scripts/verify-polyglot-fixtures.py. The advanced validator also runs the existing 26-combination checks. CSS Tree's optional source-map generator causes Angular's known CommonJS optimization warning; runtime tests and production build pass. Third-party notices are included in docs/3rdpartylicenses.txt.

Milestone 8 will connect these contracts to the generator interface. Offline application caching and abandoned-workspace cleanup remain Milestone 9.
