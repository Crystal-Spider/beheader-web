# Original processing fixtures

These small synthetic inputs were created for Beheader Web and are distributed under the project's GPL-3.0-only license. They contain no third-party photos, recordings, or sample documents.

- `transparent.png`, the static JPEG/GIF/WebP/BMP/TIFF files, animated PNG/GIF/WebP/TIFF files, and `large-dimensions.png` are generated by `python scripts/create-image-fixtures.py` with Pillow 12.0.0.
- `video-aac.mp4` is a one-second, 64×48, 10 fps H.264 baseline test pattern with a generated 440 Hz AAC-LC mono tone. `video-tail-moov.mp4` retains the video with metadata after the payload. `video-co64.mp4` uses independently rebuilt 64-bit chunk tables. Regenerate with `node scripts/create-media-fixtures.mjs`, using FFmpeg with libx264 and AAC support.
- HTML fixtures, malformed variants, and structural/encryption/codec mutations are generated directly by the tests. The browser output test adds a controlled `free` box containing markup to verify the trailing binary remains inert as HTML.

Fixture creation and independent validation use developer tools only. The application bundles neither Python nor FFmpeg and makes no media-processing network requests. Output artifacts and `independent-validation.json` are written to ignored `test-results/`, never to public assets.
